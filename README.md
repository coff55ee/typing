# typing

手元を見ずに打つ練習のための、個人用タイピング練習ページです。
公開URL: https://coff55ee.github.io/typing/

## ファイル

| ファイル | 中身 |
|---|---|
| `index.html` | 画面の骨組み（見出し・コース一覧・練習欄・実戦チェック・記録） |
| `style.css` | 見た目（色・文字・キーボードの形） |
| `data.js` | 出題する文と読み（文を足すときはここだけ直す） |
| `app.js` | 練習の動き（判定・記録・今日の1セット・実戦チェック） |
| `icon.svg` ほか | タブやブックマークのアイコン（人差し指の色の F キーと突起） |

## 文を足すとき

`data.js` の該当する配列に、同じ形で1行追加します。日本語は `["表示する文", "打つ読み"]` の組です。

## 直したあと

`index.html` の `?v=20261118` の数字を新しい日付に変えます。変えないと、ブラウザが古いファイルを使い続けることがあります。

記録はブラウザの localStorage に保存されるため、PCやブラウザごとに別々になります。
